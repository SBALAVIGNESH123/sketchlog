Why SketchLog

Stop paying to store telemetry
you never query.

Your service handles millions of requests a day. Datadog charges per host, per million events, per custom metric. New Relic bills per GB ingested. You're shipping gigabytes of raw data to someone else's cloud, and 99% of the time you just want your p99 latency.

That question doesn't need a petabyte data warehouse. It needs 84 kilobytes. SketchLog uses probabilistic data structures with published mathematical guarantees to give you the same operational signals in constant, bounded memory.

No vendor lock-in. No telemetry phone-home. No "contact sales for pricing." Free. Forever. MIT licensed.

Every sketch in SketchLog has published, peer-reviewed accuracy guarantees. These aren't benchmarks — they're theorems.

Anomaly Detection

Kolmogorov-Smirnov distance between two distributions. Detect drift in real time without a statistics degree.

🗃️

Streaming SQL

Query live sketches with SQL. SELECT p99(latency) FROM "prod/api" — no raw data needed.

🎯

Smart SLO Engine

Derive latency targets from historical data. Compute burn rates. Alert before your error budget is gone.

🌐

Sketch Mesh

Distributed gossip protocol. Merge sketches across nodes. Eventually consistent with tombstone protection.

📈

Sketch Diffing

Compare two distributions visually. KS statistic, Wasserstein distance, CDF plots, ASCII charts.

🏢

Multi-Tenancy

Namespace isolation with HMAC-scoped tokens. Per-namespace memory quotas. Full authorization enforcement.

📺

React Dashboard

Live WebSocket-streamed components. QuantileHeatmap, CDFCurve, CardinalitySparkline — plug and play.

WebAssembly

Run sketches in the browser. Merge client telemetry to the server with precision-safe 64-bit counters.

eBPF Collector

Linux kernel-level TCP timing. Zero instrumentation. Attach kprobes and stream bounded metrics to the server.

Quickstart

Three lines to your first sketch.

app.py
from sketchlog import StreamLog # One object. Three sketches. Bounded memory. log = StreamLog() # Stream latency events log.add_batch([12.5, 18.3, 22.1, 45.0, 120.7]) # Track unique users log.add_unique("user_42") # Count error events log.add_event("HTTP_500", 3) # Query instantly print(log.p99()) # ≤1% error print(log.unique_count()) # ~3% error print(log.memory_kb()) # ~84 KB
docker
# 61 MB image. Starts in 2 seconds. $ docker run -p 8000:8000 ghcr.io/sbalavignesh123/sketchlog # Ingest events $ curl -X POST localhost:8000/v1/namespaces/default/streams/api/events \ -H "Content-Type: application/json" \ -d '{"latencies": [42.5, 88.1, 12.3]}'
  • ⚡

    Zero configuration

    No bucket boundaries to tune. No sampling rates to configure. DDSketch adapts to any distribution automatically.

  • 🔒

    Crash-safe persistence

    Atomic writes with fsync + rename. Your checkpoint is never corrupted, even on power loss. Windows retry logic included.

  • 🔗

    Distributed merge

    Every sketch operation is a commutative monoid. Merge across nodes, time windows, or shards — the math guarantees correctness.

  • 🛡️

    Security-first

    HMAC auth, namespace-scoped tokens, streaming body limits, overflow-checked arithmetic, input validation at every boundary.

  • 🔌

    Integrates with everything

    OpenTelemetry, Prometheus, Grafana, FastAPI. One-line middleware. Pre-built dashboard JSON. Scrape endpoint out of the box.

  • 🧪

    Actually tested

    256 tests. Property-based with Hypothesis. Stress tests. Soak tests. Failure injection. Adversarial inputs. CI-enforced benchmark gates.
