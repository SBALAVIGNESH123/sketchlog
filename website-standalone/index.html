01 — Anomaly Detection

Detect distribution
drift instantly.

SketchLog compares a current latency sketch against an explicit baseline using the Kolmogorov-Smirnov distance. The score is between 0 and 1 — no statistics degree required. Calibrate once, alert automatically.

# Compare current vs baseline
baseline = StreamLog()
current = StreamLog()
baseline.add_batch([10, 11, 12, 13])
current.add_batch([90, 100, 110, 120])

score = current.anomaly_score(baseline)
→ 0.94 # significant drift

current.is_anomalous(baseline, sensitivity=0.2)
→ True

OpenTelemetry

Export spans and
metrics automatically.

The async OTel exporter buffers telemetry events and flushes them to the SketchLog server in the background. No code changes to your existing instrumentation — just add the exporter.

# Add to your OTel pipeline
from sketchlog.integrations.opentelemetry import (
SketchLogExporter
)

exporter = SketchLogExporter(
endpoint="http://sketchlog:8000",
namespace="prod"
)

# Attach to your trace provider
provider.add_span_processor(
BatchSpanProcessor(exporter)
)

FastAPI Middleware

One line to
instrument your app.

Drop the SketchLog middleware into any FastAPI application. It automatically captures request latencies, status codes, and endpoint cardinality — all compressed into bounded sketches.

from fastapi import FastAPI
from sketchlog import SketchLogMiddleware

app = FastAPI()

# One line. That's it.
app.add_middleware(SketchLogMiddleware)

# Every route now tracks:
# - Latency percentiles (p50/p95/p99)
# - Unique client IPs
# - Status code frequencies

Production Hardened
Built for services
that can't go down.

Security, crash safety, and operational correctness — not afterthoughts.

CS

Crash-Safe Persistence

Checkpoints use atomic writes: tempfile → fsync → os.replace → directory fsync. Your sketch state is never corrupted, even on power loss. Windows retry logic handles NTFS lock contention automatically.

SC

Security First

HMAC authentication with namespace-scoped tokens. Streaming ASGI body limits prevent buffer overflow attacks. Overflow-checked 64-bit arithmetic. Input validation at every API boundary. No eval(), no pickle, no arbitrary deserialization.

TS

Comprehensive Test Suite

256 passing tests. Property-based testing with Hypothesis. Stress tests with 8 concurrent writer threads. Soak tests for memory stability over extended runs. Failure injection with adversarial inputs: NaN, Inf, integer overflow, malformed headers.

DK

Minimal Docker Image

Multi-stage build. 61 MB image. Runs as UID 10001 (non-root). Read-only root filesystem. All capabilities dropped. seccomp profile: RuntimeDefault. Includes /health and /ready probes. Starts in under 2 seconds.

How It Works
From raw events to
bounded summaries.

No matter how many events you ingest, memory stays constant.

1

Ingest

Events arrive via HTTP API, SDK, middleware, or eBPF collector. Latencies, unique IDs, event names.

2

Compress

Each event updates the DDSketch, HyperLogLog, or Count-Min Sketch. The sketch size stays constant.

3

Query

Ask for p99, cardinality, or frequency at any time. Answers in microseconds from in-memory sketches.

4

Merge

Sketches are commutative monoids. Merge across nodes, time windows, or shards — the math guarantees correctness.
