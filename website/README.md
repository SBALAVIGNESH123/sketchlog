# SketchLog Website

This directory contains the React/Vite frontend for the SketchLog observability engine's landing page.

## Development

To run the development server:
```bash
npm install
npm run dev
```

## Build for Production

To build the static assets for production:
```bash
npm run build
```

The output will be generated in the `dist` folder.

## Architecture

This frontend is a static landing page. It uses vanilla CSS with CSS variables for a lightweight footprint, and features a responsive design, glassmorphism UI elements, and code previews.
