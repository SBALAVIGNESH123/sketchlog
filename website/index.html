example.py 
from sketchlog import SketchLog

# Connect and record latencies
sl = SketchLog("http://localhost:8080", namespace="api")
sl.record("latency/checkout", 42.7)   # ms
sl.record("latency/checkout", 38.1)
sl.record("latency/checkout", 91.2)

# Query accurate quantiles - no sampling error
p50 = sl.quantile("latency/checkout", 0.50)
p99 = sl.quantile("latency/checkout", 0.99)
print(f"p50={p50:.1f}ms  p99={p99:.1f}ms")

How it works

Three layers, one coherent pipeline.

01

Record

Your application calls sl.record(stream, value). SketchLog inserts the value into a DDSketch in memory, typically under 1ms.

02

Flush

Sketches are serialised and flushed to the SketchLog server on a configurable interval (default 10s) using the lightweight HTTP stream API.

03

Query

Query any quantile at any time window. The server merges sketches and returns a precise estimate with no sampling and no approximation from raw logs.

04

Export

Forward metrics downstream to Loki, Datadog, or New Relic with the built-in exporters. Or deploy the Kubernetes operator for fully automated cluster management.

Frequently asked questions

What is a DDSketch?

DDSketch (DataDog Sketch) is a mergeable, fully-distributed quantile sketch algorithm. It guarantees relative error, meaning the estimate for p99 is within +/-0.1% of the true value, regardless of the data distribution or value range.

How accurate are the quantile estimates?

SketchLog uses a relative error of 0.01 (1%) by default, configurable down to 0.001 (0.1%). Unlike histograms with fixed bucket boundaries, DDSketch guarantees accuracy at every percentile including the extreme tail.

Does SketchLog require any infrastructure?

No. You can run the SketchLog server with a single pip install sketchlog && sketchlog-server command. For production, a Docker image and Kubernetes Helm chart are also provided.

Can I use SketchLog in an async application?

Yes. SketchLog ships a full AsyncSketchLog client built on httpx with connection pooling, configurable retries, and native async/await support.

What exporters are available?

Loki, Datadog, and New Relic exporters are built-in, with Prometheus ingestion via the sketchlog-agent. OpenTelemetry export is on the roadmap.

Is SketchLog production-ready?

SketchLog is tested on Python 3.10-3.14 across Linux, macOS, and Windows. Every commit runs mypy strict, pyright, CodeQL, Bandit, pip-audit, stress tests, and conformance suites.
